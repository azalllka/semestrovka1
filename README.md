# HDrezka

HDrezka — это проект, который требует настройки веб-сервера, базы данных и конфигурационных файлов для правильной работы. Следуйте инструкциям ниже, чтобы настроить и запустить проект.

## Требования

- Сервер: MyWebServer
- База данных: Microsoft SQL Server (MS SQL)
- Язык программирования: C#

## Установка и настройка

### 1. Настройка конфигурации

Для корректной работы проекта вам нужно настроить файл config.json, который находится в корневой директории проекта. Заполните следующие параметры:

- Подключение к базе данных: Укажите строку подключения к вашей базе данных.
- Настройки сервера: Убедитесь, что все параметры для вашего веб-сервера правильно настроены.

### 2. Заполнение базы данных
Для работы проекта необходимо создать и заполнить базу данных. Выполните следующие шаги:

Перейдите в папку MyHttpServer.
* Воспользуйтесь файлом create_movies_table.sql для создания всех необходимых таблиц в базе данных.
* После создания таблиц выполните файл all inserts.sql, чтобы заполнить базу данных начальными данными.
* В случае ошибок или проблем с заполнением базы данных:
* Проверьте название базы данных и соответствие с настройками в config.json.

### 3. Запуск проекта
После настройки конфигурации и базы данных запустите проект.

Страницы:
* localhost:8888  (ПОРТ НА КОТОРОМ ЗАПУЩЕН СЕРВЕР из конфиг)
* localhost:8888 - главная
* /signup - регистрация
* /signin - вход
* /film?id={id} - страница фильма
может упасть при неправльном запросе
надо менять конфигурации проекта для подключения из разных источников

### **4. Краткая навигация по сайту:**
* Для начала зарегистрируйтесь на сайте (чтобы зарегистрироваться как администратор, нужно в бд в таблице Users в столбике "Role" заменить "user" на "admin" (на админ панель переходит, но она не работает))
* Войдите на сайт с помощью вашего логина и пароля
* На сайте вы можете воспользоваться поиском для нахождения нужного фильма
* Так же, зарегистрированные пользователи могут добавлять фильмы в избранные (у НЕ зарегистрированных данная кнопка есть, но она НЕ работает)
* Можно посмотреть фильм, но для этого в базе данных в столбце TrailerUrl необхожимо исправить ссылку
(убрать букву w перед словом trailer, должно быть так: assets/trailers/green_mile_trailer.mp4, а не так: assets/wtrailers/green_mile_trailer.mp4).
Это сделано для того, чтобы сайт быстрее работал (с изначально верно указанными ссылками на всех фильмах, сайт может долго грузить)
* Так же, на сайте есть адаптив

### 5. Возможные проблемы
Убедитесь, что используется Microsoft SQL Server (MS SQL), так как проект не совместим с другими типами баз данных.

### 6. Важная информация
Проект HDrezka всё ещё находится в разработке, и могут возникать баги. Он может не запускаться корректно на некоторых типах операционных систем.
